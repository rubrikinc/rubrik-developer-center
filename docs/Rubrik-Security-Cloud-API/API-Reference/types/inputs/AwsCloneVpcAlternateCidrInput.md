# AwsCloneVpcAlternateCidrInput

AwsCloneVpcAlternateCidr clones VPCs with remapped CIDR blocks (one AwsVpcCidrMapping entry per VPC).

|-------|------|-------------|
| vpcCidrMappings | [[AwsVpcCidrMappingInput](AwsVpcCidrMappingInput.md)!]! | Per-VPC CIDR remapping configuration. |
