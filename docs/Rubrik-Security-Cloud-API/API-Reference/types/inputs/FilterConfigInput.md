# FilterConfigInput

FilterConfig represents an individual filter, including its type, values, and relationship.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| filterType | [FilterType](../enums/FilterType.md)! | The type of the filter. |
| relationship | [Relationship](../enums/Relationship.md)! | The relationship between this filter type and values. |
| values | [String!]! | The values for this filter. |
