# IrisdbSlaConfigInput

Input to configure the SLA Domain for IRIS DB instances.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| logFrequency | [SlaDurationInput](SlaDurationInput.md) | Frequency value for the log backup of IRIS DB instances. |
| logRetention | [SlaDurationInput](SlaDurationInput.md) | Specifies the duration for which the IRIS DB instance logs will be retained. |
