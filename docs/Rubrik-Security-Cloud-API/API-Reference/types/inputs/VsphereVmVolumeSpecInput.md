# VsphereVmVolumeSpecInput

VSphere virtual machine volume specification.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| dataStoreCdmId | String | CDM ID of the datastore. |
| dataStoreId | String | Datastore ID for the volume. |
| datastoreClusterId | String | Datastore cluster ID if using datastore cluster. |
| key | String | Device key for vsphere volume identification. |
| label | String | Label for the volume. |
| sizeGbs | Float | Size of the volume in GB. |
