# PrivateContainerRegistryInput

Input to retrieve Private Container Registry details.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| exocomputeAccountId | [UUID](../scalars/UUID.md)! | The associated "cloud" account ID for which the PCR will be used. For CNP, this is the same as cloud_account_id. For M365-like clusters, this is the org_id. |
