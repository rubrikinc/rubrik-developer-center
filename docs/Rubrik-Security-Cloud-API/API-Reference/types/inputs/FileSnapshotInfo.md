# FileSnapshotInfo

Represents the OneDrive file snapshot to be restored. Represents a snapshot of a file to be restored.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| fileSize | [Long](../scalars/Long.md)! | Size of the file in bytes. |
| snapshotId | [UUID](../scalars/UUID.md)! | UUID of the snapshot. |
| snapshotNum | Int! | Sequence number of the snapshot. |
