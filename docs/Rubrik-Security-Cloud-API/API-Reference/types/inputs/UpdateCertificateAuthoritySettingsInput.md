# UpdateCertificateAuthoritySettingsInput

Input to update the certificate authority settings.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| issuedCertificateLifetimeInDays | Int | The number of days for which the issued certificates are valid. |
| renewBeforeExpirationInDays | Int | Number of days before which a certificate issued by this certificate authority must be renewed. |
