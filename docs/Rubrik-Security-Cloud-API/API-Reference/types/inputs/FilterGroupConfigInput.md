FilterGroupConfig represents a group of filters with a logical operator.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| filterList | [[FilterNode](FilterNode.md)!]! | A list of filters in this group. |
| logicalOp | [LogicalOperator](../enums/LogicalOperator.md)! | The logical operator applied to this group of filters. |
