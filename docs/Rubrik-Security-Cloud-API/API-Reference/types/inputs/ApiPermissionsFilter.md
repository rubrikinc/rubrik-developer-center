# ApiPermissionsFilter

ApiPermissionsFilter represents the filter to be applied when retrieving the API permissions if any.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| isPrivileged | Boolean | Filter by privileged API permissions. |
| nativeCreationTime | [DateTimeRangeUserAccess](DateTimeRangeUserAccess.md) | Filter by native creation time range. |
