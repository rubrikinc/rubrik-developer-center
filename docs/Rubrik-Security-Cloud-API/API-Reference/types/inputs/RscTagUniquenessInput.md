# RscTagUniquenessInput

Input for RSC tag uniqueness validation.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| key | String | Key of the RSC tag (for key-value tags, optional). |
| name | String | Name of the RSC tag (for legacy single-value tags). |
| value | String | Value of the RSC tag (for new single-value or key-value tags). |
