# ClassificationDataTypeIdToMaskingTechnique

Maps a classification data type ID to a masking technique.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| dataTypeId | [UUID](../scalars/UUID.md)! | ID of the classification data type. |
| maskingTechnique | [MaskingTechnique](../enums/MaskingTechnique.md)! | Single masking technique for this data type. |
