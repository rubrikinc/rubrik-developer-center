# FusionComputeUpdatedUnmountTimeInput

Supported in v9.6+ Configuration for updating the scheduled unmount time of a FusionCompute Live Mount.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| newUnmountTime | [Long](../scalars/Long.md)! | Required. Supported in v9.6+ The absolute new unmount time in epoch milliseconds. |
