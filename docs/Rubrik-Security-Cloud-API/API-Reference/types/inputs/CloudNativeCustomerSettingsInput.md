# CloudNativeCustomerSettingsInput

Cloud-native customer settings to update. Only fields that are provided are persisted; omitted fields are left unchanged.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| isS3GlacierIrTierEnabled | Boolean | Whether S3 objects in the Glacier Instant Retrieval storage class are included in backups. If omitted, the current value is left unchanged. |
