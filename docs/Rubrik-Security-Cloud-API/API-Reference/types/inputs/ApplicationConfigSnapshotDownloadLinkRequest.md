# ApplicationConfigSnapshotDownloadLinkRequest

Request to get a download link for a config snapshot of a cloud native application.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| applicationId | [UUID](../scalars/UUID.md)! | Application managed object ID. |
| snapshotId | [UUID](../scalars/UUID.md)! | Config snapshot ID to download. |
