# SetTempServiceProviderInput

Sets a temporary service provider for an account. This is used only for testing purposes.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| encryptionCertificateFid | String | FID of the encryption certificate to use for the temporary service provider. |
| signingCertificateFid | String | FID of the signing certificate to use for the temporary service provider. |
| useDefaultEncryptionCert | Boolean | Specifies whether the default encryption certificate should be used. |
| useDefaultSigningCert | Boolean | Specifies whether the default signing certificate should be used. |
