# UnRecoveredDcInfoInput

Input for information about an unrecovered domain controller.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| domainName | String! | Required. Supported in v9.4+ Name of the domain. |
| domainSid | String! | Required. Supported in v9.4+ Domain security identifier. |
| fqdn | String! | Required. Supported in v9.4+ Fully qualified domain name of the unrecovered domain controller. |
