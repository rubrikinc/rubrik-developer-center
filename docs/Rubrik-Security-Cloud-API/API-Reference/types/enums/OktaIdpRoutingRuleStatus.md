# OktaIdpRoutingRuleStatus

Lifecycle status for IdP Discovery Policy routing rules.

## Values

| Value | Description |
|-------|-------------|
| OKTA_IDP_ROUTING_RULE_STATUS_ACTIVE | Active routing rule. |
| OKTA_IDP_ROUTING_RULE_STATUS_INACTIVE | Inactive routing rule. |
| OKTA_IDP_ROUTING_RULE_STATUS_UNSPECIFIED | Unspecified routing rule status. |
