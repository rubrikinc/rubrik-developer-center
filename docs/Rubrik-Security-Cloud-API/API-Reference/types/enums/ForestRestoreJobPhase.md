# ForestRestoreJobPhase

Forest restore job phase.

## Values

| Value | Description |
|-------|-------------|
| CDM_JOBS_QUEUED | Forest Restore jobs are queued for execution. |
| COMPLETED | Forest restore job has completed. |
| HEALTH_CHECKS | Forest Restore validating health checks. |
| HEALTH_CHECK_RETRY | Health checks are being retried. |
| HOST_PROMOTION | Forest Restore promoting hosts to domain controllers. |
| HOST_PROMOTION_JOBS_QUEUED | Forest Restore promote hosts jobs are queued for execution. |
| JOB_PHASE_UNSPECIFIED | Forest Restore job phase is unspecified. |
| OTHER_DCS_RECOVERY | Forest Restore restoring remaining domain controllers. |
| ROOT_DC_RECOVERY | Forest Restore restoring the root domain controller. |
| SNAPSHOT_DOWNLOAD | Forest Restore downloading snapshots from archival locations. |
| START_CDM_JOBS | Forest Restore initiating restoration jobs. |
