# AzureAdTenantType

Specifies the Microsoft cloud environment that the tenant belongs to.

## Values

| Value | Description |
|-------|-------------|
| COMMERCIAL | Commercial (public) Microsoft cloud tenant. |
| GCC | US Government Community Cloud (GCC) tenant. |
| GCC_HIGH | US Government Community Cloud High (GCC High) tenant. |
| TENANT_TYPE_UNSPECIFIED | Tenant type is unspecified (maps to NULL in the database). |
