# TimeUnitEnum

The unit of time that a time range is truncated to.

## Values

| Value | Description |
|-------|-------------|
| Day | The time range is truncated to a day. |
| Hour | The time range is truncated to an hour. |
| Month | The time range is truncated to a month. |
| Quarter | The time range is truncated to a quarter. |
| Week | The time range is truncated to a week. |
| Year | The time range is truncated to a year. |
