# OktaIdentityProviderSortByField

Sortable fields for OktaIdentityProviders. Per the UI granular-recovery contract, identity providers are sortable by Name only.

## Values

| Value | Description |
|-------|-------------|
| OKTA_IDENTITY_PROVIDER_SORT_BY_NAME | Sort by identity provider name. |
| OKTA_IDENTITY_PROVIDER_SORT_BY_UNSPECIFIED | Unspecified sort field. |
