# QuiesceTargetTargetType

Workload type of a Pure Storage protection group quiesce target.

## Values

| Value | Description |
|-------|-------------|
| QUIESCE_TARGET_TARGET_TYPE_RBA_HOST | The target is an RBA-installed host. |
| QUIESCE_TARGET_TARGET_TYPE_VMWARE_VM | The target is a VMware virtual machine. |
