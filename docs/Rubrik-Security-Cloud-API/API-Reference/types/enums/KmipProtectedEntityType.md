# KmipProtectedEntityType

The type of entity that uses a KMIP server.

## Values

| Value | Description |
|-------|-------------|
| KMIP_PROTECTED_ENTITY_TYPE_CDM | Rubrik CDM cluster. Routing-only discriminator; never persisted to kmip_assignments. |
| KMIP_PROTECTED_ENTITY_TYPE_RSCP_CLUSTER | Rubrik RSC-P cluster. |
| KMIP_PROTECTED_ENTITY_TYPE_UNSPECIFIED | Unspecified. |
