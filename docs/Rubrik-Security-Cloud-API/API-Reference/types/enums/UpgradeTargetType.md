# UpgradeTargetType

What a Rubrik CDM upgrade package is being uploaded for.

## Values

| Value | Description |
|-------|-------------|
| UPGRADE_TARGET_TYPE_APPLIANCE | The RSC-P appliance. |
| UPGRADE_TARGET_TYPE_CLUSTER | One or more Rubrik CDM clusters. |
| UPGRADE_TARGET_TYPE_UNSPECIFIED | The target is not set. |
