# DataSizeFormatType

All reporting storage data sizes.

## Values

| Value | Description |
|-------|-------------|
| DATA_SIZE_FORMAT_TYPE_UNSPECIFIED | Default Storage Format. |
| STORAGE_UNIT_GB | Storage Units in GB. |
| STORAGE_UNIT_GIB | Storage Units in GiB (binary, 1024^3 bytes). |
| STORAGE_UNIT_KB | Storage Units in KB. |
| STORAGE_UNIT_KIB | Storage Units in KiB (binary, 1024^1 bytes). |
| STORAGE_UNIT_MB | Storage Units in MB. |
| STORAGE_UNIT_MIB | Storage Units in MiB (binary, 1024^2 bytes). |
| STORAGE_UNIT_PB | Storage Units in PB. |
| STORAGE_UNIT_PIB | Storage Units in PiB (binary, 1024^5 bytes). |
| STORAGE_UNIT_TB | Storage Units in TB. |
| STORAGE_UNIT_TIB | Storage Units in TiB (binary, 1024^4 bytes). |
