# ChartViewType

All valid chart views.

## Values

| Value | Description |
|-------|-------------|
| BACKUP_STRIKES_CHART | Backup strikes chart showing number of objects with and without strikes. |
| CHART_UNSPECIFIED | The chart view type is unspecified. |
| CLOUD_COST_CHART | Cloud Cost Report chart displaying cost breakdown over time. |
| COMPLIANCE_STATUS_ALL_CHART | Compliance report charts The Compliance report's donut chart showing the compliance status of all objects. |
| COMPLIANCE_STATUS_CLUSTER_CHART | The Compliance report's bar chart showing the compliance status of each cluster. |
| COMPLIANCE_STATUS_CLUSTER_TYPE_CHART | The Compliance report's bar chart showing the compliance status of each cluster type. |
| COMPLIANCE_STATUS_OBJECT_TYPE_CHART | The Compliance report's bar chart showing the compliance status of each object type. |
| DATA_DISCOVERY_SENSITIVE_FILES_CHART | The Data Discovery Object Details report includes a bar chart displaying the number of sensitive files for each workload. |
| DATA_DISCOVERY_SENSITIVE_HITS_CHART | The Data Discovery Object Details report includes a bar chart displaying the number of sensitive hits for each workload. |
| EVENT_SERIES_ALL_CHART | The Events report's donut chart showing the number of events. |
| EVENT_SERIES_BY_CLUSTER_CHART | The Events report's bar chart showing the number of events by cluster. |
| EVENT_SERIES_BY_CLUSTER_TYPE_CHART | The Events report's bar chart showing the number of events by cluster type. |
| EVENT_SERIES_BY_OBJECT_TYPE_CHART | The Events report's bar chart showing the number of events by object type. |
| EVENT_SERIES_BY_TIME_CHART | The Events report's line chart showing the number of events over time. |
| INDEXING_REPORT_BY_OBJECT_CHART | The Indexing report's bar chart showing the indexing status of each object. |
| INDEXING_REPORT_BY_SLA_CHART | The Indexing report's bar chart showing the objects' indexing status of each SLA Domain. |

| INFRASTRUCTURE_BY_TYPE_CHART | The Infrastructure report's donut chart showing the number of clusters for each cluster type. |
| OBJECT_BACKUP_TASK_SUMMARY_BY_SLA_CHART | The Object Backup Task Summary Report's chart showing backup data of each SLA Domain. |
| OBJECT_BACKUP_TASK_SUMMARY_MISSED_TASK_BY_OBJECT_CHART | The Object Backup Task Summary Report's chart showing the top 10 objects with the most missed tasks. |
| OBJECT_CAPACITY_ALL_CHART | The Object Capacity report's donut chart showing the capacity of all objects. |
| OBJECT_CAPACITY_BY_CLUSTER_CHART | The Object Capacity report's donut chart showing the object capacity of each cluster. |

| OBJECT_CAPACITY_BY_OBJECT_TYPE_SOURCE_SIZE_CHART | The Object Capacity report's donut chart showing the source size of each object type. |
| OBJECT_CAPACITY_OVERTIME_ARCHIVE_STORAGE_CHART | Archive storage chart for the Object Capacity Over Time report. |
| OBJECT_CAPACITY_OVERTIME_LOCAL_DATA_STORE_CHART | Local data store chart for the object-capacity-over-time report. |
| OBJECT_CAPACITY_OVERTIME_LOGICAL_SIZE_CHART | Logical size chart for the Object Capacity Over Time report. |
| OBJECT_CAPACITY_OVERTIME_PROTECTED_OBJECTS_COUNT_CHART | Protected objects count chart for the object-capacity-over-time report. |
| OBJECT_CAPACITY_OVERTIME_SOURCE_SIZE_CHART | Source size chart for the object-capacity-over-time report. |
| OBJECT_CAPACITY_OVERTIME_TRANSFERRED_BYTES_CHART | Transferred bytes chart for the Object Capacity Over Time report. |
| PROTECTION_ALL_CHART | The Protection report's donut chart showing the protection status of all objects. |

| PROTECTION_BY_CLUSTER_TYPE_CHART | The Protection report's bar chart showing the protection status of each cluster type. |
| PROTECTION_BY_OBJECT_TYPE_CHART | The Protection report's bar chart showing the protection status of each object type. |
