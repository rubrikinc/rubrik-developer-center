# MariadbDatabaseProtectionState

Represents the protection state of the MariaDB database.

## Values

| Value | Description |
|-------|-------------|
| FULLY_PROTECTED | The MariaDB database is fully protected. |
| FULLY_UNPROTECTED | The MariaDB database is fully unprotected. |
| PARTIALLY_PROTECTED | The MariaDB database is partially protected. |
| PROTECTION_STATE_UNSPECIFIED | Unspecified protection state. |
