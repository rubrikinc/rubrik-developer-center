# GcpLocationType

Describes how data is stored and replicated in the GCS Bucket.

## Values

| Value | Description |
|-------|-------------|
| DUAL_REGION | GCS Bucket exists in specific pair of regions. |
| MULTI_REGION | GCS Bucket exists in multiple regions. |
| REGION | GCS Bucket exists in a specified region. |
| UNKNOWN | Unknown GCS Bucket Location type. |
