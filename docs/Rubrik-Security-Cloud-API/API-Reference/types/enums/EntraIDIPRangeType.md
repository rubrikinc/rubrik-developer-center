# EntraIDIPRangeType

EntraIDIPRangeType represents the type of Entra ID IP range.

## Values

| Value | Description |
|-------|-------------|
| EID_IP_RANGE_TYPE_IPV4_CIDR | IP range is of IPV4 CIDR type. |
| EID_IP_RANGE_TYPE_IPV6_CIDR | IP range is of IPV6 CIDR type. |
| EID_IP_RANGE_TYPE_UNSPECIFIED | Unspecified IP range type. |
