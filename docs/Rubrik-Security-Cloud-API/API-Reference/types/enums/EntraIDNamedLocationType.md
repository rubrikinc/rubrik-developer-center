# EntraIDNamedLocationType

EntraIDNamedLocationType represents the type of Entra ID named location.

## Values

| Value | Description |
|-------|-------------|
| EID_NL_TYPE_COUNTRY | Named location type is of country type. |
| EID_NL_TYPE_IP | Named location is of IP type. |
| EID_NL_TYPE_UNSPECIFIED | Unspecified named location type. |
