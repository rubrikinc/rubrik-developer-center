# SupportCaseStatusFilter

Status filter for support cases.

## Values

| Value | Description |
|-------|-------------|
| SUPPORT_CASE_FILTER_CLOSED | Matches closed statuses: Closed, Closed - Complete, Closed - No Action, Closed - Duplicate, Closed - Spam. |
| SUPPORT_CASE_FILTER_OPEN | Matches all non-closed SFDC statuses. |
| SUPPORT_CASE_FILTER_UNSPECIFIED | No status filter applied. |
