# ForestRecoveryDcStatus

Supported in v9.2+ v9.2: Status of the DC during Forest Recovery. v9.3+: Status of the domain controller during Forest Recovery.

## Values

| Value | Description |
|-------|-------------|
| FOREST_RECOVERY_DC_STATUS_CANCELED | The forest recovery job of the domain controller is canceled. |
| FOREST_RECOVERY_DC_STATUS_COMPLETED | The forest recovery job of the domain controller is completed. |
| FOREST_RECOVERY_DC_STATUS_FAILED | The forest recovery job of the domain controller failed. |
| FOREST_RECOVERY_DC_STATUS_IN_PROGRESS | The forest recovery job of the domain controller is in progress. |
| FOREST_RECOVERY_DC_STATUS_QUEUED | The forest recovery job of the domain controller is queued. |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_ALL_DCS_HEALTH_CHECKS |  |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_ALL_DCS_IN_DSRM_MODE |  |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_ALL_DCS_RECOVERY |  |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_OTHER_DCS_RECOVERY | The forest recovery job of the domain controller is queued after other domain controllers are recovered. |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_ROOT_DCS_HEALTH_CHECKS | The forest recovery job of the domain controller is queued after the health checks of the root domain controller. |
| FOREST_RECOVERY_DC_STATUS_QUEUED_AFTER_ROOT_DC_RECOVERY | The forest recovery job of the domain controller is queued after the root domain controller is recovered. |
| FOREST_RECOVERY_DC_STATUS_RESOLVE_NOW_TO_RESUME | The forest recovery job of the domain controller is paused because of an issue and needs to be resolved to resume. |
| FOREST_RECOVERY_DC_STATUS_RETRYING_HEALTH_CHECK | The forest recovery job of the domain controller is retrying the health check. |
| FOREST_RECOVERY_DC_STATUS_UNABLE_TO_UPDATE_STATUS | Unable to update the status of the forest recovery job of the domain controller. |
| FOREST_RECOVERY_DC_STATUS_WAITING_ON_RSC_TO_START |  |
