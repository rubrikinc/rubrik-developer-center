# ForceDeleteEligibilityReason

One of the reasons for eligibility of force delete cloud account.

## Values

| Value | Description |
|-------|-------------|
| CONNECTED_ACCOUNT_NOT_ALLOWED | Deletion of a connected cloud account is not allowed. |
| NON_CNP_ACCOUNT_NOT_SUPPORTED | Data center account deletion is not supported. |
| PENDING_ARCHIVAL_SLA_CLEANUP | Some archival SLA Domains are using the cloud account. |
| PENDING_EXOCOMPUTE_MAPPING_CLEANUP | Some cloud account is using this cloud account for Exocompute. |
| PENDING_REPLICATION_SLA_CLEANUP | Some replication SLA Domains are using the cloud account. |
| REQUIREMENTS_SATISFIED | All the requirements are satisfied. |
| UNKNOWN | Reason is unknown. |
