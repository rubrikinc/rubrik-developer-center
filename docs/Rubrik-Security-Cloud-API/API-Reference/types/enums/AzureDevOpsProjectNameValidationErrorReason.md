# AzureDevOpsProjectNameValidationErrorReason

Reason for Azure DevOps project name validation failure.

## Values

| Value | Description |
|-------|-------------|
| AZURE_DEVOPS_PROJECT_NAME_VALIDATION_ERROR_REASON_ALREADY_EXISTS | A project with the same name already exists in the destination organization. |
| AZURE_DEVOPS_PROJECT_NAME_VALIDATION_ERROR_REASON_INVALID_CHARACTERS | The name contains forbidden printable characters, control characters, or invalid start/end characters. |
| AZURE_DEVOPS_PROJECT_NAME_VALIDATION_ERROR_REASON_LENGTH_EXCEEDED | The name is empty or blank, or exceeds the 64 Unicode character limit. |
| AZURE_DEVOPS_PROJECT_NAME_VALIDATION_ERROR_REASON_RESERVED_NAME | The name is a system reserved name or IIS hidden segment. |
| AZURE_DEVOPS_PROJECT_NAME_VALIDATION_ERROR_REASON_UNSPECIFIED | Default unspecified failure reason. |
