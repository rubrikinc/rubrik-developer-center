# GcpBigQueryDatasetSortFields

Fields to sort GCP BigQuery datasets.

## Values

| Value | Description |
|-------|-------------|
| EFFECTIVE_SLA_DOMAIN | Sort by SLA Domain. |
| GCP_BIG_QUERY_DATASET_NATIVE_ID | Sort by dataset native ID. |
| GCP_BIG_QUERY_DATASET_PROJECT_NAME | Sort by project name. |
| NAME | Sort by dataset name. |
