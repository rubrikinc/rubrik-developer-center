# ApplicationRecoveryOutcome

Outcome of an application recovery.

## Values

| Value | Description |
|-------|-------------|
| RECOVERY_OUTCOME_FAILED | Recovery failed. |
| RECOVERY_OUTCOME_PARTIALLY_SUCCEEDED | Recovery partially succeeded. |
| RECOVERY_OUTCOME_SUCCEEDED | Recovery succeeded. |
| RECOVERY_OUTCOME_UNSPECIFIED | Outcome is not yet known. |
