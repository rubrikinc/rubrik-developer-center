# RefreshHarmfulLifecyclePoliciesStatus

Outcome of an on-demand harmful lifecycle policies refresh request.

## Values

| Value | Description |
|-------|-------------|
| REFRESH_HARMFUL_LIFECYCLE_POLICIES_STATUS_ALREADY_IN_PROGRESS | A harmful lifecycle policies refresh is already in progress for this account; no new refresh was started. |
| REFRESH_HARMFUL_LIFECYCLE_POLICIES_STATUS_STARTED | A new harmful lifecycle policies refresh was started. |
| REFRESH_HARMFUL_LIFECYCLE_POLICIES_STATUS_UNSPECIFIED | Default. Should never appear in a response. |
