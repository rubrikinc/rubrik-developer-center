# ProvisioningMethod

ProvisioningMethod is the authentication method for Azure Key Vault.

## Values

| Value | Description |
|-------|-------------|
| CLOUD_ACCOUNT_PROVISION | Credentials resolved from an onboarded RSC Cloud Account (Cloud Native Archives). |
| DIRECT_PROVISION | Static secrets (Data Center Archives). |
| PROVISION_METHOD_UNSPECIFIED | The type was unspecified. |
| SECURE_PROVISION | Managed identity (Data Center Archives) -- Azure only. |
