# AzureAdObjectAttributeDifferenceEnumType

Specifies the difference between the live environment and the snapshot value.

## Values

| Value | Description |
|-------|-------------|
| ADDED | The attribute's value is added. |
| DELETED | The attribute's value is removed. |
| MODIFIED | The attribute's value has been modified. |
| UNKNOWN_ATTRIBUTE_DIFFERENCE_TYPE | Attribute difference is unknown. |
| UNMODIFIED | The attribute's value has not been modified. |
