# SensitiveDataSummary

SensitiveDataSummary contains the sensitive data summary and breakdown (if requested) based on filter criteria.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| breakdown | [SensitiveDataSummaryBreakdown](SensitiveDataSummaryBreakdown.md) | Breakdown of sensitive data summary for the given filter. |
| totalRiskSummary | [TotalRiskSummary](TotalRiskSummary.md) | Total risk summary for the given filter. |
