# EntraIDRoleProperties

EntraIDRoleProperties contains properties specific to EntraID roles.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| hasRiskyPermissions | Boolean! | Represents whether the role has risky permissions. |
| isPrivileged | Boolean! | Represents whether the role is privileged or not. |
| roleDescription | String! | Represents the role description. |
| type | [EntraIDRoleType](../enums/EntraIDRoleType.md)! |  |
