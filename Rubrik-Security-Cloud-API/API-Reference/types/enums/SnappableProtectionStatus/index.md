# SnappableProtectionStatus

Represents the protection status type.

## Values

| Value              | Description                     |
| ------------------ | ------------------------------- |
| DO_NOT_PROTECT     | Do not protect.                 |
| NATIVE_PROTECTION  | Workload is natively protected. |
| RSC_PROTECTED      | RSC protected.                  |
| UNKNOWN_PROTECTION | Unknown.                        |
