# ArchivalUploadJobPauseAction

Action to apply to an archival upload job.

## Values

| Value                                   | Description                                  |
| --------------------------------------- | -------------------------------------------- |
| ARCHIVAL_UPLOAD_JOB_PAUSE_ACTION_PAUSE  | Pause the job at its next pausable boundary. |
| ARCHIVAL_UPLOAD_JOB_PAUSE_ACTION_RESUME | Resume a paused job.                         |
