# ActivitySeriesGroupByEnum

Field to group activity series by.

## Values

| Value              | Description                                                                |
| ------------------ | -------------------------------------------------------------------------- |
| Cluster            | Group activity series by Rubrik cluster, specified by Rubrik cluster UUID. |
| ClusterType        | Group activity series by Rubrik cluster type.                              |
| Day                | Group activity series by day.                                              |
| Hour               | Group activity series by hour.                                             |
| LastActivityStatus | Group activity series by last activity status.                             |
| LastActivityType   | Group activity series by last activity type.                               |
| Month              | Group activity series by month.                                            |
| ObjectType         | Group activity series by object type.                                      |
| Quarter            | Group activity series by quarter.                                          |
| Week               | Group activity series by week.                                             |
| Year               | Group activity series by year.                                             |
