# VsphereSupervisorStatus

Status of a vSphere Supervisor.

## Values

| Value       | Description                                    |
| ----------- | ---------------------------------------------- |
| CONFIGURING | The Supervisor is being configured.            |
| DEGRADED    | The Supervisor is running with reduced health. |
| ERROR       | The Supervisor is in an error state.           |
| RUNNING     | The Supervisor is running.                     |
