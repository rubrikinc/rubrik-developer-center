# RelationshipType

Specifies the type of relationship between an app item and its parent in the cascading hierarchy.

## Values

| Value   | Description                                                               |
| ------- | ------------------------------------------------------------------------- |
| CHILD   | App item is the child.                                                    |
| PARENT  | App item is the parent.                                                   |
| UNKNOWN | The relationship is unknown when one of the app item types doesn't exist. |
