# ForestRecoveryStepStatus

Supported in v9.2+ Status of the forest recovery step.

## Values

| Value                                             | Description                                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| FOREST_RECOVERY_STEP_STATUS_CANCELED              | The forest recovery step is canceled.                                                      |
| FOREST_RECOVERY_STEP_STATUS_COMPLETED             | The forest recovery step is completed.                                                     |
| FOREST_RECOVERY_STEP_STATUS_FAILED                | The forest recovery step failed.                                                           |
| FOREST_RECOVERY_STEP_STATUS_FAILURE_ACKNOWLEDGED  | The forest recovery step failure is acknowledged.                                          |
| FOREST_RECOVERY_STEP_STATUS_IN_PROGRESS           | The forest recovery step is in progress.                                                   |
| FOREST_RECOVERY_STEP_STATUS_QUEUED                | The forest recovery step is queued.                                                        |
| FOREST_RECOVERY_STEP_STATUS_RESOLVE_NOW_TO_RESUME | The forest recovery step is paused because of an issue and needs to be resolved to resume. |
| FOREST_RECOVERY_STEP_STATUS_RETRYING              | The forest recovery step is retrying.                                                      |
| FOREST_RECOVERY_STEP_STATUS_RETRY_FAILED          | The forest recovery step retry failed.                                                     |
