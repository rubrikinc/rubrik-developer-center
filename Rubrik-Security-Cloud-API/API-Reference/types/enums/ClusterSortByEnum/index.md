# ClusterSortByEnum

Property to order the cluster list results.

## Values

| Value                   | Description                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AVAILABLE_SPACE_PERCENT | Percentage of available storage space in the cluster.                                                                                                                                                                                                                                                                                                                                                                                |
| CLUSTER_LOCATION        | Location of the Rubrik cluster.                                                                                                                                                                                                                                                                                                                                                                                                      |
| ClusterName             | Rubrik cluster name.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ClusterType             | Rubrik cluster type, ordered by the label the cluster list shows in its Type column rather than by the `type` value. NAS Cloud Direct clusters, whose `type` is Robo, sort as their own label, so clusters that share a `type` are not always adjacent. In ascending order the labels are Appliance, Cloud, ExoCompute, NAS Cloud Direct virtual machine, Rubrik, Rubrik Virtual Cluster, Rubrik Virtual Vault, Unknown and Virtual. |
| ESTIMATED_RUNWAY        | Estimated time before cluster runs out of storage.                                                                                                                                                                                                                                                                                                                                                                                   |
| INSTALLED_VERSION       | Version of the installed Rubrik cluster.                                                                                                                                                                                                                                                                                                                                                                                             |
| RegisteredAt            | Rubrik cluster registration date.                                                                                                                                                                                                                                                                                                                                                                                                    |
