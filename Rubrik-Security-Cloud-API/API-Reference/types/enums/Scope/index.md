| Value                             | Description                                 |

| GCP_PROJECT_SCOPE                 | GCP Project Level Scope without Conditions. |
| GCP_PROJECT_WITH_CONDITIONS_SCOPE | GCP Project Level Scope with Conditions.    |
| RESOURCE_GROUP_SCOPE              | Resource group-level scope.                 |
| SCOPE_UNSPECIFIED                 | Scope is not specified.                     |
| SUBSCRIPTION_SCOPE                | Subscription-level scope.                   |
