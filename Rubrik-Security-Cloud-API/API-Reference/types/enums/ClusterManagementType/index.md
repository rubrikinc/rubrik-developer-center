# ClusterManagementType

Who operates a Rubrik cluster.

## Values

| Value                          | Description                                                  |
| ------------------------------ | ------------------------------------------------------------ |
| MANAGEMENT_TYPE_RUBRIK_MANAGED | Rubrik operates the Rubrik cluster on the customer's behalf. |
| MANAGEMENT_TYPE_SELF_MANAGED   | The customer operates the Rubrik cluster.                    |
| MANAGEMENT_TYPE_UNSPECIFIED    | The management type of the Rubrik cluster is not specified.  |
