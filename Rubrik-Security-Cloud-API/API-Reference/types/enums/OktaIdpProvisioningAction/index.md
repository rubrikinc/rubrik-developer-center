# OktaIdpProvisioningAction

JIT provisioning action for Okta Identity Providers.

## Values

| Value                                    | Description                                    |
| ---------------------------------------- | ---------------------------------------------- |
| OKTA_IDP_PROVISIONING_ACTION_AUTO        | Auto-provision matched users on first sign-in. |
| OKTA_IDP_PROVISIONING_ACTION_DISABLED    | JIT provisioning is turned off for the IdP.    |
| OKTA_IDP_PROVISIONING_ACTION_UNSPECIFIED | Unspecified provisioning action.               |
