# OktaIdpStatus

Lifecycle status for Okta Identity Providers.

## Values

| Value                       | Description                 |
| --------------------------- | --------------------------- |
| OKTA_IDP_STATUS_ACTIVE      | Active identity provider.   |
| OKTA_IDP_STATUS_INACTIVE    | Inactive identity provider. |
| OKTA_IDP_STATUS_UNSPECIFIED | Unspecified status.         |
