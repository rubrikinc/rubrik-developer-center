# VsphereNamespaceStatus

Status of a vSphere Namespace.

## Values

| Value       | Description                         |
| ----------- | ----------------------------------- |
| CONFIGURING | The Namespace is being configured.  |
| ERROR       | The Namespace is in an error state. |
| REMOVING    | The Namespace is being removed.     |
| RUNNING     | The Namespace is running.           |
