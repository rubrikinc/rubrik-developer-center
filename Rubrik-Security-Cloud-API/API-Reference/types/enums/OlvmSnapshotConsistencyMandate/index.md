# OlvmSnapshotConsistencyMandate

Snapshot consistency mandate for OLVM virtual machines.

## Values

| Value                                              | Description                       |
| -------------------------------------------------- | --------------------------------- |
| OLVM_SNAPSHOT_CONSISTENCY_MANDATE_APP_CONSISTENT   | Application consistent snapshots. |
| OLVM_SNAPSHOT_CONSISTENCY_MANDATE_AUTOMATIC        | Automatic consistency (default).  |
| OLVM_SNAPSHOT_CONSISTENCY_MANDATE_CRASH_CONSISTENT | Crash consistent snapshots.       |
