# CloudNativeApplicationRefreshStatus

Refresh status of a cloud native application.

## Values

| Value                          | Description                       |
| ------------------------------ | --------------------------------- |
| APP_REFRESHING                 | App refresh is in progress.       |
| APP_REFRESH_FAILED             | App refresh failed.               |
| APP_REFRESH_STATUS_UNSPECIFIED | Unspecified App refresh status.   |
| APP_REFRESH_SUCCESS            | App refresh status is successful. |
