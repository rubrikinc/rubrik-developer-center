# RpoLagLevel

The severity level indicating how far a workload's actual RPO deviates from its expected RPO.

## Values

| Value         | Description                                               |
| ------------- | --------------------------------------------------------- |
| HIGH          | The RPO lag significantly exceeds the expected threshold. |
| LOW           | The RPO lag is within acceptable limits.                  |
| MEDIUM        | The RPO lag moderately exceeds the expected threshold.    |
| NOT_AVAILABLE | RPO lag information is not available for this workload.   |
