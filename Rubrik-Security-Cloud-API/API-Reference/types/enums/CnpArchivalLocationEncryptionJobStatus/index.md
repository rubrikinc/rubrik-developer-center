# CnpArchivalLocationEncryptionJobStatus

Status of a key-management operation for an archival location.

## Values

| Value                                                   | Description                   |
| ------------------------------------------------------- | ----------------------------- |
| CNP_ARCHIVAL_LOCATION_ENCRYPTION_JOB_STATUS_FAILED      | The operation failed.         |
| CNP_ARCHIVAL_LOCATION_ENCRYPTION_JOB_STATUS_IN_PROGRESS | The operation is in progress. |
| CNP_ARCHIVAL_LOCATION_ENCRYPTION_JOB_STATUS_QUEUED      | The operation is queued.      |
| CNP_ARCHIVAL_LOCATION_ENCRYPTION_JOB_STATUS_SUCCEEDED   | The operation succeeded.      |
| CNP_ARCHIVAL_LOCATION_ENCRYPTION_JOB_STATUS_UNSPECIFIED | The status is unspecified.    |
