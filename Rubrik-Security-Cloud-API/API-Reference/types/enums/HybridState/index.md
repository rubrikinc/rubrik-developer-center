# HybridState

Hybrid state of identity.

## Values

| Value                    | Description                       |
| ------------------------ | --------------------------------- |
| CLOUD_ONLY               | Identity exists only on cloud.    |
| HYBRID                   | Identity is in hybrid state.      |
| HYBRID_STATE_UNSPECIFIED | Unspecified hybrid state.         |
| ONPREM_ONLY              | Identity exists only on premises. |
