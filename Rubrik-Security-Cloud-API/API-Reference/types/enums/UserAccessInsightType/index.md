# UserAccessInsightType

UserAccessInsightType represents the type of user access insight.

## Values

| Value             | Description                                                                          |
| ----------------- | ------------------------------------------------------------------------------------ |
| ACL_CHANGE        | Insight corresponds to new users getting access to sensitive data due to ACL change. |
| AD_CHANGE         | Insight corresponds to new users getting access to sensitive data due to AD change.  |
| CONTENT_CHANGE    | Insight corresponds to new sensitive data.                                           |
| UA_CONTENT_CHANGE | Insight corresponds to users getting access to new sensitive data.                   |
