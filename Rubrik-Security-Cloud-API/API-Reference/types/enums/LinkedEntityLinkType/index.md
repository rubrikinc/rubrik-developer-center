# LinkedEntityLinkType

LinkedEntityLinkType indicates how the entity is linked (directly or via inheritance/nesting).

## Values

| Value                 | Description                               |
| --------------------- | ----------------------------------------- |
| LINK_TYPE_DIRECT      | Entity is directly linked.                |
| LINK_TYPE_NESTED      | Entity is linked via nesting/inheritance. |
| LINK_TYPE_UNSPECIFIED | Unspecified link type.                    |
