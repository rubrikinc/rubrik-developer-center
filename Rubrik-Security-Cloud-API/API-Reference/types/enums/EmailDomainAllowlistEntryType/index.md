# EmailDomainAllowlistEntryType

Type of entry in the email domain allowlist.

## Values

| Value                                         | Description             |
| --------------------------------------------- | ----------------------- |
| EMAIL_DOMAIN_ALLOWLIST_ENTRY_TYPE_DOMAIN      | Domain entry type.      |
| EMAIL_DOMAIN_ALLOWLIST_ENTRY_TYPE_EMAIL       | Email entry type.       |
| EMAIL_DOMAIN_ALLOWLIST_ENTRY_TYPE_UNSPECIFIED | Unspecified entry type. |
