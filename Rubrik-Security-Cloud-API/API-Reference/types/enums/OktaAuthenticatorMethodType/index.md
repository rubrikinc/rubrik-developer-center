# OktaAuthenticatorMethodType

Okta Authenticator Method Type Enums. Named after Okta's own authenticator method "type" values so the mapping needs no translation.

## Values

| Value                                  | Description                                         |
| -------------------------------------- | --------------------------------------------------- |
| AUTHENTICATOR_METHOD_CERT              | Certificate.                                        |
| AUTHENTICATOR_METHOD_DUO               | Duo Security.                                       |
| AUTHENTICATOR_METHOD_EMAIL             | Email.                                              |
| AUTHENTICATOR_METHOD_IDP               | Federated identity provider.                        |
| AUTHENTICATOR_METHOD_NFC_PIN           | Smart card or NFC security key unlocked with a PIN. |
| AUTHENTICATOR_METHOD_OTP               | One-time passcode.                                  |
| AUTHENTICATOR_METHOD_PASSWORD          | Password.                                           |
| AUTHENTICATOR_METHOD_PUSH              | Push notification.                                  |
| AUTHENTICATOR_METHOD_SECURITY_QUESTION | Security question.                                  |
| AUTHENTICATOR_METHOD_SIGNED_NONCE      | Signed nonce (Okta FastPass).                       |
| AUTHENTICATOR_METHOD_SMS               | SMS.                                                |
| AUTHENTICATOR_METHOD_TAC               | Temporary Access Code.                              |
| AUTHENTICATOR_METHOD_TOTP              | Time-based one-time passcode.                       |
| AUTHENTICATOR_METHOD_UNSPECIFIED       | Unspecified method.                                 |
| AUTHENTICATOR_METHOD_VOICE             | Voice call.                                         |
| AUTHENTICATOR_METHOD_WEBAUTHN          | WebAuthn.                                           |
