# ActivityClassification

The classification assigned to an activity in Identity Resilience.

## Values

| Value       | Description                                 |
| ----------- | ------------------------------------------- |
| CLASSIFYING | The activity is currently being classified. |
| LEGITIMATE  | The activity is classified as legitimate.   |
| SUSPICIOUS  | The activity is classified as suspicious.   |
| UNKNOWN     | The activity's classification is unknown.   |
