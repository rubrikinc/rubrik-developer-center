# GpoStatus

GPO enablement status.

## Values

| Value                      | Description                                 |
| -------------------------- | ------------------------------------------- |
| COMPUTER_SETTINGS_DISABLED | Computer settings are not enabled.          |
| DISABLED                   | User and computer settings are not enabled. |
| ENABLED                    | User and computer settings are enabled.     |
| UNKNOWN                    | Unknown GPO status.                         |
| USER_SETTINGS_DISABLED     | User settings are not enabled.              |
