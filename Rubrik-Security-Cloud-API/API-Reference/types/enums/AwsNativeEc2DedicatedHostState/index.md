# AwsNativeEc2DedicatedHostState

State of an AWS EC2 Dedicated Host.

## Values

| Value                            | Description                                              |
| -------------------------------- | -------------------------------------------------------- |
| AVAILABLE                        | Dedicated host is available.                             |
| DEDICATED_HOST_STATE_UNSPECIFIED | Dedicated host state is not specified.                   |
| PENDING                          | Dedicated host is in pending state.                      |
| PERMANENT_FAILURE                | Dedicated host has had a permanent failure.              |
| RELEASED                         | Dedicated host has been released.                        |
| RELEASED_PERMANENT_FAILURE       | Dedicated host has been released with permanent failure. |
| UNDER_ASSESSMENT                 | Dedicated host is under assessment.                      |
