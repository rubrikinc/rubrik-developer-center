# AwsSecretRegionEnabledState

AWS secret region enabled state.

## Values

| Value                         | Description                             |
| ----------------------------- | --------------------------------------- |
| AWS_SECRET_REGION_DCA_ENABLED | AWS Top Secret region (C2S) is enabled. |
| AWS_SECRET_REGION_DISABLED    | AWS secret region feature is disabled.  |
| AWS_SECRET_REGION_LCK_ENABLED | AWS Secret region (SC2S) is enabled.    |
