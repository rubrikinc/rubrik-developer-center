# IntuneSettingItemKeyType

Specifies the type of label that identifies a Setting row in a collection.

## Values

| Value                                    | Description              |
| ---------------------------------------- | ------------------------ |
| INTUNE_SETTING_ITEM_KEY_TYPE_DEVICE_NAME | The type is device name. |
| INTUNE_SETTING_ITEM_KEY_TYPE_NAME        | The type is name.        |
| INTUNE_SETTING_ITEM_KEY_TYPE_UNKNOWN     | The type is unknown.     |
