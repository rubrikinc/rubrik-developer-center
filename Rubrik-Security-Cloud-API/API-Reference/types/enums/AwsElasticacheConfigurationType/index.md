# AwsElasticacheConfigurationType

Configuration type of an AWS Elasticache cluster.

## Values

| Value                                                | Description                      |
| ---------------------------------------------------- | -------------------------------- |
| AWS_ELASTICACHE_CONFIGURATION_TYPE_CACHE_CLUSTER     | Cache cluster configuration.     |
| AWS_ELASTICACHE_CONFIGURATION_TYPE_REPLICATION_GROUP | Replication group configuration. |
| AWS_ELASTICACHE_CONFIGURATION_TYPE_SERVERLESS        | Serverless configuration.        |
