# OktaProfileMappingStatus

Profile mapping presence for an application or identity provider at browse time.

## Values

| Value                                   | Description                                         |
| --------------------------------------- | --------------------------------------------------- |
| OKTA_PROFILE_MAPPING_STATUS_ABSENT      | No profile mappings were configured at backup time. |
| OKTA_PROFILE_MAPPING_STATUS_PRESENT     | Profile mappings were configured at backup time.    |
| OKTA_PROFILE_MAPPING_STATUS_UNSPECIFIED | Status was not determined.                          |
