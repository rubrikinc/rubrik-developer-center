# EmailDomainAllowlistEntriesSortByField

Available fields for sorting email domain allowlist entries.

## Values

| Value       | Description            |
| ----------- | ---------------------- |
| CREATED_AT  | Sort by creation time. |
| ENTRY_TYPE  | Sort by entry type.    |
| ENTRY_VALUE | Sort by entry value.   |
| UNKNOWN     | Default field.         |
