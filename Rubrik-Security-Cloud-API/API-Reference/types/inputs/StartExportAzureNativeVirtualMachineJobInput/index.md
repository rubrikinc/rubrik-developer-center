# StartExportAzureNativeVirtualMachineJobInput

Input for the job to export an Azure virtual machine from a snapshot.

## Fields

| Field                             | Type                                                                                                                              | Description                                                                                                                                                                                                                                                           |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| archivedSnapshotId                | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)                          | ID of the archived snapshot to export. This field should be specified only when `snapshotType` is set to `Archived`.                                                                                                                                                  |
| availabilitySetNativeId           | String                                                                                                                            | Native ID of the availability set the exported virtual machine joins.                                                                                                                                                                                                 |
| destinationAvailabilityZone       | String                                                                                                                            | Availability zone the virtual machine is exported to. Leave empty for regions or virtual machine sizes that do not support availability zones.                                                                                                                        |
| destinationKeyVaultName           | String                                                                                                                            | Name of the key vault created in the destination region. Required for cross-region export of virtual machines with Azure Disk Encryption enabled.                                                                                                                     |
| destinationRegion                 | [AzureNativeRegion](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/AzureNativeRegion/index.md)! | Azure region the virtual machine is exported to.                                                                                                                                                                                                                      |
| destinationSubscriptionRubrikId   | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)                          | Rubrik ID of the Azure subscription the virtual machine is exported to. When empty, the virtual machine is exported to the subscription it was backed up from.                                                                                                        |
| diskEncryptionSetNativeId         | String                                                                                                                            | Native ID of the disk encryption set used to encrypt the disks created for the exported virtual machine.                                                                                                                                                              |
| networkSecurityGroupNativeId      | String                                                                                                                            | Native ID of the network security group applied to the exported virtual machine.                                                                                                                                                                                      |
| recoveryDiskIds                   | \[[UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!\]                     | Specifies a list of Azure disk unique native IDs that will be exported. When empty, all disks from the snapshot will be exported.                                                                                                                                     |
| recoveryPurpose                   | [RecoveryPurpose](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/RecoveryPurpose/index.md)      | Purpose of the recovery operation. Set to SURGICAL_RECOVERY to automatically exclude quarantined files from the exported virtual machine (subject to feature availability for the account). Defaults to RECOVERY_PURPOSE_UNSPECIFIED, which preserves prior behavior. |
| resourceGroupName                 | String!                                                                                                                           | Name of the resource group the exported virtual machine is created in.                                                                                                                                                                                                |
| shouldEnableAcceleratedNetworking | Boolean                                                                                                                           | Specifies whether accelerated networking is enabled on the exported virtual machine.                                                                                                                                                                                  |
| shouldExportTags                  | Boolean!                                                                                                                          | Specifies whether the tags at the time of the snapshot are applied to the exported virtual machine.                                                                                                                                                                   |
| shouldPowerOff                    | Boolean!                                                                                                                          | Specifies whether the exported virtual machine is powered off after the export completes.                                                                                                                                                                             |
| shouldUseReplica                  | Boolean                                                                                                                           | Specifies whether the replica of the snapshot is used for the export. Ignored when `snapshotType` is specified.                                                                                                                                                       |
| snapshotId                        | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!                         | Snapshot ID of the snapshot from which the virtual machine is exported.                                                                                                                                                                                               |
| snapshotType                      | [AzureSnapshotType](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/AzureSnapshotType/index.md)  | Copy of the snapshot to export from. Defaults to the replica when `shouldUseReplica` is true, and to the source snapshot otherwise.                                                                                                                                   |
| subnetNativeId                    | String!                                                                                                                           | Native ID of the subnet the exported virtual machine is attached to.                                                                                                                                                                                                  |
| virtualMachineName                | String!                                                                                                                           | Name of the exported virtual machine.                                                                                                                                                                                                                                 |
| virtualMachineSize                | String!                                                                                                                           | Azure size of the exported virtual machine.                                                                                                                                                                                                                           |
