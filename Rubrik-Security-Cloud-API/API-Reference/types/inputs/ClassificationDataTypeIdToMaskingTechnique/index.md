# ClassificationDataTypeIdToMaskingTechnique

Maps a classification data type ID to a masking technique.

## Fields

| Field            | Type                                                                                                                            | Description                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| dataTypeId       | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!                       | ID of the classification data type.          |
| maskingTechnique | [MaskingTechnique](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/MaskingTechnique/index.md)! | Single masking technique for this data type. |
