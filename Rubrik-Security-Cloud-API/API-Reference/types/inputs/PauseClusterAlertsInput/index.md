# PauseClusterAlertsInput

Input for pausing alerts from a Rubrik cluster.

## Fields

| Field       | Type                                                                                                      | Description                                                     |
| ----------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| clusterUuid | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)! | UUID of the Rubrik cluster from which alerts need to be paused. |
