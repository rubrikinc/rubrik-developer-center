| Field | Type                                                                                                                           | Description                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| key   | String                                                                                                                         | The name for the new node.             |
| value | [NodeConfigInput](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/inputs/NodeConfigInput/index.md)! | The IP configuration for the new node. |
