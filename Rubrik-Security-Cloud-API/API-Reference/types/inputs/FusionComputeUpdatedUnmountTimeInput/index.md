# FusionComputeUpdatedUnmountTimeInput

Supported in v9.6+ Configuration for updating the scheduled unmount time of a FusionCompute Live Mount.

## Fields

| Field          | Type                                                                                                      | Description                                                                       |
| -------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| newUnmountTime | [Long](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/Long/index.md)! | Required. Supported in v9.6+ The absolute new unmount time in epoch milliseconds. |
