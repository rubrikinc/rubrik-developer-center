# GetArchivalReaderInfoReq

Input for getting the reader location details of an archival location.

## Fields

| Field | Type                                                                                                      | Description                                                                                                           |
| ----- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| id    | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)! | ID of an archival location managed by Rubrik Security Cloud. Locations managed by a Rubrik cluster are not supported. |
