# QueryRCVReadersOwnerEncryptionKeyInput

Input for fetching the owner location's encryption key settings of a Rubrik Cloud Vault reader location.

## Fields

| Field            | Type                                                                                                      | Description                                   |
| ---------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| readerLocationId | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)! | ID of the Rubrik Cloud Vault reader location. |
