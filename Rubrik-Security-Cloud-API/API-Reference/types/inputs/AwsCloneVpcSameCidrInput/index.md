# AwsCloneVpcSameCidrInput

AwsCloneVpcSameCidr clones VPCs using the same CIDR blocks as the snapshot.

## Fields

| Field        | Type    | Description                                                        |
| ------------ | ------- | ------------------------------------------------------------------ |
| preserveCidr | Boolean | If true, preserve the original CIDR blocks from the snapshot VPCs. |
