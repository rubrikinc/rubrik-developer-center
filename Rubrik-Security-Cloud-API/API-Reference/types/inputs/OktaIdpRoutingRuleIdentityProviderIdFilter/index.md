# OktaIdpRoutingRuleIdentityProviderIdFilter

Identity-provider-id filter for Okta IdP Discovery routing rules. Returns rules whose IdpsInclude array contains any of the specified IdPs.

## Fields

| Field  | Type       | Description                                       |
| ------ | ---------- | ------------------------------------------------- |
| values | [String!]! | Identity provider IDs to filter routing rules by. |
