# NcdCredential

NcdCredential is a single named credential for a generic S3 system. Used both when adding a system and for post-import credential management.

## Fields

| Field    | Type    | Description          |
| -------- | ------- | -------------------- |
| name     | String! | Tenant display name. |
| password | String! | S3 secret key.       |
| username | String! | S3 access key.       |
