# ChildRestoreItemCriteria

Criteria specifying details for child items to be restored.

## Fields

| Field       | Type                                                                                                                          | Description                                                  |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| recordLimit | Int                                                                                                                           | Optional, limits the number of child records to be restored. |
| sortByParam | [SaasSortByParam](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/inputs/SaasSortByParam/index.md) | Optional, field and order used to sort the child records.    |
