# AwsNetworkingSettingsInput

AwsNetworkingSettings specifies the VPC strategy for AWS application recovery. Exactly one vpcOption must be set.

## Fields

| Field     | Type                                                                                                                        | Description                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| vpcOption | [VpcOptionInput](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/inputs/VpcOptionInput/index.md) | VPC strategy for the recovery. |
