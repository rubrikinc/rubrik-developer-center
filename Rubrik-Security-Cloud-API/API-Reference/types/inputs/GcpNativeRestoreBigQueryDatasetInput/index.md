# GcpNativeRestoreBigQueryDatasetInput

Input required to restore from a BigQuery dataset snapshot.

## Fields

| Field                         | Type                                                                                                                                    | Description                                                                                                                                                  |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| recoveryMode                  | [BigQueryRecoveryMode](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/BigQueryRecoveryMode/index.md)! | Discriminator selecting the recovery data source. Required.                                                                                                  |
| recoveryTime                  | [DateTime](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/DateTime/index.md)                        | Point-in-time to recover to. Required when recoveryMode is PITR; must be unset otherwise. The time must fall within the source dataset's time-travel window. |
| shouldAddRubrikLabels         | Boolean!                                                                                                                                | Specifies whether to add Rubrik labels to the restored entities or not.                                                                                      |
| shouldRestoreLabels           | Boolean!                                                                                                                                | Specifies whether to restore labels from the snapshot or not.                                                                                                |
| snapshotId                    | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)                                | Snapshot Rubrik ID. Required when recoveryMode is SNAPSHOT_BASED; must be unset otherwise.                                                                   |
| sourceBigQueryDatasetRubrikId | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!                               | Rubrik UUID of the source BigQuery dataset. Required for both recovery modes.                                                                                |
| tablesToBeRestored            | [String!]!                                                                                                                              | Tables to be restored.                                                                                                                                       |
