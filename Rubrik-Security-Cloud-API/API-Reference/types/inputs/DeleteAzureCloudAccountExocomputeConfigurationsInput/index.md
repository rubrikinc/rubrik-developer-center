AzureExocomputeConfigsDeleteReq defines the request for deleting the exocompute configs specified by the exocompute_config_ids.

| cloudAccountIds | \[[UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!\]! | Rubrik IDs of the cloud accounts to be deleted. |
