# AwsVpcIdMappingInput

AwsVpcIdMapping maps a source VPC ID to an existing target VPC ID.

## Fields

| Field       | Type    | Description                       |
| ----------- | ------- | --------------------------------- |
| sourceVpcId | String! | Source VPC ID to map from.        |
| targetVpcId | String! | Existing target VPC ID to map to. |
