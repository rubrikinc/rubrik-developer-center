| dataCategoryIds | [String!]!                                                                                                                           | The data type will be added to the provided data categories. |
| dataType        | [DataTypeDefinition](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/inputs/DataTypeDefinition/index.md)! | The details of the custom data type being created.           |
