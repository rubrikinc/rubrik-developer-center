# SalesforceRestoreConfig

SalesforceRestoreConfig contains Salesforce-specific configurations for restore.

## Fields

| Field                 | Type    | Description                                                                       |
| --------------------- | ------- | --------------------------------------------------------------------------------- |
| disableAutomations    | Boolean | Salesforce automations are to be turned off for the duration of the recovery job. |
| restoreObjectMetadata | Boolean | Specifies whether to restore metadata during object restore.                      |
