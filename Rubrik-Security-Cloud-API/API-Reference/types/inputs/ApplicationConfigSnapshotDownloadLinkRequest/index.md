# ApplicationConfigSnapshotDownloadLinkRequest

Request to get a download link for a config snapshot of a cloud native application.

## Fields

| Field         | Type                                                                                                      | Description                     |
| ------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------- |
| applicationId | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)! | Application managed object ID.  |
| snapshotId    | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)! | Config snapshot ID to download. |
