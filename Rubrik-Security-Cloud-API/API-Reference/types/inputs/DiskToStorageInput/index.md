# DiskToStorageInput

Mapping of disk to storage for Proxmox virtual machine export.

## Fields

| Field     | Type    | Description                                     |
| --------- | ------- | ----------------------------------------------- |
| diskId    | String! | Required. Supported in v9.5+ ID of the disk.    |
| storageId | String! | Required. Supported in v9.5+ ID of the storage. |
