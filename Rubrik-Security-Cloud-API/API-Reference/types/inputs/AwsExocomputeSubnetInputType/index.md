AwsExocomputeSubnet is a subset of the message type Subnet with the fields required for exocompute.

| ---------------- | ------- | -------------------------------- |
| availabilityZone | String! | Availability zone of the subnet. |
| podSubnetId      | String  | Subnet ID of the pod subnet.     |
| subnetId         | String! | AWS ID of subnet.                |
