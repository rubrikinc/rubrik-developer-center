# AgentCloudPolicyFilter

Filter for policies. Set fields combine: a policy must match each. A list left out or empty does not filter, except subscriptions, which defaults to ADDED.

| Field            | Type                                                                                                                                                                | Description                                                                                                                                                 |

| frameworkNames   | [String!]                                                                                                                                                           | Names of compliance frameworks the policy maps to.                                                                                                          |
| ids              | \[[UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!\]                                                       | Policy IDs.                                                                                                                                                 |

| packIds          | \[[UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!\]                                                       | IDs of packs that contain the policy.                                                                                                                       |
