# CloudNativeTagPair

A cloud-native tag key-value pair.

## Fields

| Field             | Type       | Description                                    |
| ----------------- | ---------- | ---------------------------------------------- |
| key               | String!    | Tag key.                                       |
| matchAllTagValues | Boolean!   | Indicates if all tag values should be matched. |
| values            | [String!]! | List of tag values.                            |
