# AdContactMetadata

On-prem AD contact-specific metadata.

## Fields

| Field        | Type    | Description                                    |
| ------------ | ------- | ---------------------------------------------- |
| company      | String! | Specifies the company of the contact.          |
| email        | String! | Specifies the email address of the contact.    |
| office       | String! | Specifies the office location of the contact.  |
| organisation | String! | Specifies the organisation of the contact.     |
| telephone    | String! | Specifies the telephone number of the contact. |
