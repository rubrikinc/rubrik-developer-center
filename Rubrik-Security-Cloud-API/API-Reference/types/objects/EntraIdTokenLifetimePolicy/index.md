# EntraIdTokenLifetimePolicy

Represents a token lifetime policy.

## Fields

| Field                 | Type     | Description                                             |
| --------------------- | -------- | ------------------------------------------------------- |
| accessTokenLifetime   | String!  | Lifetime of the access token.                           |
| displayName           | String!  | Display name of the token lifetime policy.              |
| id                    | String!  | ID of the token lifetime policy.                        |
| isOrganizationDefault | Boolean! | Whether the policy is the default for the organization. |
