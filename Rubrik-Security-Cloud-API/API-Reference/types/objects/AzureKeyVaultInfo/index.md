# AzureKeyVaultInfo

Azure Key Vault specific information.

**Implements:** [KeyVaultInfo](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/interfaces/KeyVaultInfo/index.md)

## Fields

| Field                       | Type                                                                                                                                         | Description                                                                                                                                                                                                                                               |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| clientId                    | String!                                                                                                                                      | Client ID of the Azure Key Vault.                                                                                                                                                                                                                         |
| cloudAccountId              | String                                                                                                                                       | Onboarded RSC Cloud Account (Azure subscription) backing this vault. Empty for DIRECT/SECURE vaults. Mirrors AwsKmsInfo.cloud_account_id.                                                                                                                 |
| isRscConnectivityRestricted | Boolean!                                                                                                                                     | When true, RSC never connects to the vault; only the execution layer (CDM, Exocompute, Exotask) does. Defaults to false.                                                                                                                                  |
| keyVaultType                | [KmsType](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/KmsType/index.md)!                                | The type of Key Vault.                                                                                                                                                                                                                                    |
| keyVaultUrl                 | String!                                                                                                                                      | URL of the Azure Key Vault.                                                                                                                                                                                                                               |
| kmsKeyVaultId               | [UUID](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/scalars/UUID/index.md)!                                    | KMS UUID of the Azure Key Vault.                                                                                                                                                                                                                          |
| kmsSubscriptionId           | String                                                                                                                                       | Azure subscription ID of a restricted vault. Empty when RSC connects to the vault.                                                                                                                                                                        |
| provisioningMethod          | [ProvisioningMethod](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/ProvisioningMethod/index.md)!          | Provisioning method of the Azure Key Vault.                                                                                                                                                                                                               |
| region                      | [AzureCloudAccountRegion](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/enums/AzureCloudAccountRegion/index.md) | Azure region of the Key Vault. UNKNOWN_AZURE_REGION when the region is not known yet, which can be the case for DIRECT/SECURE vaults. Uses the cloudaccounts region enum so Exocompute APIs, which take the same type, can consume it without conversion. |
| resourceGroupName           | String                                                                                                                                       | Resource group of a restricted vault. Empty when RSC connects to the vault.                                                                                                                                                                               |
| tenantId                    | String!                                                                                                                                      | Tenant ID of the Azure Key Vault.                                                                                                                                                                                                                         |
