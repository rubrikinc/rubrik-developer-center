# Path

Path of the AWS organization children.

## Fields

| Field       | Type    | Description                                                                                            |
| ----------- | ------- | ------------------------------------------------------------------------------------------------------ |
| displayPath | String! | Absolute path display name of the children in the hierarchy. example - /Root/Pro-Org/CustomerAccount . |
| idPath      | String! | Absolute path of the children in the hierarchy. example - /r-er2f/ou-w2ry/1234567 .                    |
