# SensitiveDataSummary

SensitiveDataSummary contains the sensitive data summary and breakdown (if requested) based on filter criteria.

| breakdown        | [SensitiveDataSummaryBreakdown](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/objects/SensitiveDataSummaryBreakdown/index.md) | Breakdown of sensitive data summary for the given filter. |
