# ResourceGroupInfo

ResourceGroupInfo stores the resource group information for Azure workloads.

## Fields

| Field | Type    | Description                               |
| ----- | ------- | ----------------------------------------- |
| id    | String! | Specifies the ID of the resource group.   |
| name  | String! | Specifies the name of the resource group. |
