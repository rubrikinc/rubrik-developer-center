# AboutInformation

Additional information about a vCenter object, such as name, version, OS type, and API type. Only available on clusters 5.1+.

## Fields

| Field   | Type    | Description              |
| ------- | ------- | ------------------------ |
| apiType | String! | API type of the vCenter. |
| name    | String! | Name of the vCenter.     |
| osType  | String! | OS type of the vCenter.  |
| version | String! | Version of the vCenter.  |
