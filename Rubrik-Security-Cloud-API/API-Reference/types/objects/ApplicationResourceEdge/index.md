| ------ | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| cursor | String!                                                                                                                                 | String used to identify this edge.                          |
| node   | [ApplicationResource](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/objects/ApplicationResource/index.md)! | The actual ApplicationResource object wrapped by this edge. |
