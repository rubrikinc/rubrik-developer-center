# DiffPath

DiffPath is the ordered FriendlyName chain (root..leaf) locating one changed leaf node within a GPO settings diff tree.

## Fields

| Field    | Type       | Description                                      |
| -------- | ---------- | ------------------------------------------------ |
| segments | [String!]! | Ordered FriendlyName segments from root to leaf. |
