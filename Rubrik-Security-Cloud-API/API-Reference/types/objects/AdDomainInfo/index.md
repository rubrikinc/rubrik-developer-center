# AdDomainInfo

AdDomainInfo is a lightweight AD domain summary.

## Fields

| Field | Type    | Description                          |
| ----- | ------- | ------------------------------------ |
| name  | String! | Display name of the domain (FQDN).   |
| sid   | String! | AD domain SID (e.g. "S-1-5-21-..."). |
