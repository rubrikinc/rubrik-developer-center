# RvcDeploymentToolLink

Response for the request to get download links for the Rubrik Virtual Cluster Deployment Tool.

## Fields

| Field               | Type    | Description                                    |
| ------------------- | ------- | ---------------------------------------------- |
| linuxDownloadLink   | String! | Download link for the Linux binary of RVCDT.   |
| macOsDownloadLink   | String! | Download link for the MacOS binary of RVCDT.   |
| windowsDownloadLink | String! | Download link for the Windows binary of RVCDT. |
