| Field           | Type    | Description                  |
| --------------- | ------- | ---------------------------- |
| keyId           | String! | The ID of the KMS key vault. |
| kmsKeyVaultId   | String! | The KMS key vault's ID.      |
| kmsKeyVaultName | String! | The KMS key vault's name.    |
