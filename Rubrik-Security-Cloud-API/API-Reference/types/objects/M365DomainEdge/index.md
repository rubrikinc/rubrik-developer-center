# M365DomainEdge

Wrapper around the M365Domain object. This wrapper is used for pagination.

## Fields

| Field  | Type                                                                                                                  | Description                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| cursor | String!                                                                                                               | String used to identify this edge.                 |
| node   | [M365Domain](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/objects/M365Domain/index.md)! | The actual M365Domain object wrapped by this edge. |
