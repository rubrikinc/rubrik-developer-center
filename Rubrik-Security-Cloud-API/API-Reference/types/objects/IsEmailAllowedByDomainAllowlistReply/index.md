# IsEmailAllowedByDomainAllowlistReply

Response indicating whether the given email is permitted by the email domain allowlist.

## Fields

| Field     | Type     | Description                                                          |
| --------- | -------- | -------------------------------------------------------------------- |
| isAllowed | Boolean! | True if the email is permitted, or if the allowlist is not enforced. |
