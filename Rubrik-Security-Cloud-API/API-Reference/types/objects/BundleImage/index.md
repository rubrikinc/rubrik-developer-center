# BundleImage

List of exo-task images in the bundle.

## Fields

| Field | Type    | Description                                                                            |
| ----- | ------- | -------------------------------------------------------------------------------------- |
| name  | String! | Contains the name of exo-task image.                                                   |
| sha   | String! | Contains the SHA value of exotask image. Only one of `sha` or `tag` will be available. |
| tag   | String! | Contains the tag value of exotask image. Only one of `sha` or `tag` will be available. |
