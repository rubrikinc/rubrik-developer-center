# CloudNativeApplicationEdge

Wrapper around the CloudNativeApplication object. This wrapper is used for pagination.

## Fields

| Field  | Type                                                                                                                                          | Description                                                    |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| cursor | String!                                                                                                                                       | String used to identify this edge.                             |
| node   | [CloudNativeApplication](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/objects/CloudNativeApplication/index.md)! | The actual CloudNativeApplication object wrapped by this edge. |
