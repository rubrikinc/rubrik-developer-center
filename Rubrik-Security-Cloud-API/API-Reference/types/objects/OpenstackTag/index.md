# OpenstackTag

An OpenStack tag. A tag is scoped to a single project, so the same Nova tag name in two projects is two distinct objects.

**Implements:** [CdmHierarchyObject](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/interfaces/CdmHierarchyObject/index.md), [HierarchyObject](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/interfaces/HierarchyObject/index.md), [OpenstackProjectDescendantType](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/interfaces/OpenstackProjectDescendantType/index.md), [OpenstackProjectLogicalChildType](https://developer.rubrik.com/Rubrik-Security-Cloud-API/API-Reference/types/interfaces/OpenstackProjectLogicalChildType/index.md)
