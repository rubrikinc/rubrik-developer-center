# AdComputerMetadata

On-prem AD computer specific metadata.

## Fields

| Field     | Type    | Description                               |
| --------- | ------- | ----------------------------------------- |
| dnsName   | String! | Specifies the DNS name of the computer.   |
| location  | String! | Specifies the location of the computer.   |
| os        | String! | Specifies the OS of the computer.         |
| osVersion | String! | Specifies the OS version of the computer. |
