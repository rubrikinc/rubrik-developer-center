# CloudNativeCustomerSettings

Cloud-native customer settings for an account. Each field is an independent toggle.

## Fields

| Field                    | Type     | Description                                                                                |
| ------------------------ | -------- | ------------------------------------------------------------------------------------------ |
| isS3GlacierIrTierEnabled | Boolean! | Whether S3 objects in the Glacier Instant Retrieval storage class are included in backups. |
