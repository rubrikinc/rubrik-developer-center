# AzureLocalResourceGroup

An ARM resource group eligible as an export destination.

## Fields

| Field | Type    | Description                                                                                                                            |
| ----- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| name  | String! | Resource group name. Uniquely identifies the resource group within the subscription that is derived from the caller's hypervClusterId. |
