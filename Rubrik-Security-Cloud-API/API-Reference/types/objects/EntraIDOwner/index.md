# EntraIDOwner

EntraIDOwner describes a user which is an owner of an object within the Entra ID environment.

## Fields

| Field       | Type    | Description                          |
| ----------- | ------- | ------------------------------------ |
| name        | String! | The name of the owner.               |
| principalId | String! | The principal ID (SID) of the owner. |
