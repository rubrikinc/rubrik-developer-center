# rcvCustomerSpecificString

Returns the account-specific prefix used in the names of the caller's Rubrik Cloud Vault Azure storage accounts.

## Returns

String!

## Sample

```graphql
query {
  rcvCustomerSpecificString
}
```

```json
{}
```

```json
  "data": {
    "rcvCustomerSpecificString": "example-string"
  }
}
```
